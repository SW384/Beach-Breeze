# Beach Breeze
Beach Breeze is a website meant to help people plan the perfect beach day.

## Features
- Home page with beach themed design and music
- Interactive list tracker tab for packing
- Interactive vacation schedule
- Beach clean-up mini game with multiple options for timers
- Custom jellyfish cursor

## AI Usage
I used AI to help me figure out how sections in HTML work, and what to write for the JS to let me switch between the sections. I also used AI to help me figure out some basics for CSS, like how to make all buttons in a section be edited at once, and to create the image I used for the custom cursor. It also helped me write some of the mini game code, but the majority was me writing after I had it explain how to make the mini game.
